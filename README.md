# MPATE-GE 2623 Music Info Retrievel Final Project: <br> Chord Recognition Using Symbolic Data

<b> Is it viable to generate datasets of chord labels using only symbolic (MIDI) data, good enough for the training and evaluation of existing chord recognizers? </b>

This is the code for the accompanying paper. Included is:
 - chord_pipeline.ipynb, which walks through the high-level steps of generating the chord labels and evaluating
 - process_crema.ipynb, which generates the crema outputs
 - utils.py, which houses all functions

If you want to run the code yourself, as it stands the chord_pipeline.ipynb tutorial will mount to Google Drive and install the ('baby') slakh dataset. Please make sure you have added utils.py to your files in order for the code to work properly!
